# RADAR_history

急診戰情圖 · 歷史回溯 2020–2024

互動式儀表板,回溯呈現急診壅塞相關指標(占床率、EDWIN、NEDOCS、READI、等候時間等)的歷史趨勢,並與同期 COVID-19 月統計數據對照。

## 內容

- `index.html` / `TCH急診戰情_歷史回溯_2020-2024.html` — 自含式互動儀表板(資料已內嵌,可直接開啟或透過 GitHub Pages 瀏覽)
- `master_hourly.csv` — 每小時原始指標資料
- `monthly_summary.csv` — 月統計摘要
- `monthly/` — 各月份明細 CSV
- `taiwan_covid_monthly.csv` — 台灣 COVID-19 月統計對照資料
- `surge_months.json` — 急診壅塞/到院量異常月份標記
- `png/`, `overview_2020_2024.png`, `validation_covid.png` — 圖表輸出
